# Open Data Jawa Barat – Postal Code Dataset (2023)

This folder archives the original distribution files
published via Open Data Jawa Barat.

## Files

- dispusipda-kode_pos_kab_kota_indonesia_data.csv  
  Original CSV distribution as published by the source.
- dispusipda-kode_pos_kab_kota_indonesia_metadata.pdf  
  Official metadata document describing the dataset.

## Notes

- Production year: 2023
- Coverage: national (village/kelurahan level)
- This dataset is not an authoritative source for postal codes.

## Integrity

File integrity can be verified using the provided SHA-256 checksums:

```bash
sha256sum -c SHA256SUMS
```
